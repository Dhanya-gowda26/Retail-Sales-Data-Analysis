# Retail Sales Data Analysis

## Project Overview
This project analyzes retail sales data using Python to identify sales trends, customer behavior, product performance, and payment preferences.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
The dataset contains 1,000 retail transactions with information about:
- Branch and City
- Customer Type
- Gender
- Product Line
- Unit Price
- Quantity
- Total Sales
- Payment Method
- Customer Rating

## Analysis Performed
- Data loading and exploration
- Missing value checking
- Statistical analysis
- Sales analysis by product line
- Sales analysis by city
- Payment method analysis
- Customer type analysis
- Gender-wise sales analysis
- Monthly sales trend
- Customer rating analysis
- Correlation analysis
- Data visualization

## Key Insights
- Food and beverages generated the highest total sales.
- Naypyitaw recorded the highest total sales among the cities.
- E-wallet was the most commonly used payment method.
- Food and beverages received the highest average customer rating.
- Female customers generated slightly higher total sales than male customers.
- Member customers generated higher total sales than normal customers.
- January had the highest monthly sales.
- Quantity and total sales showed a strong positive relationship.

## Conclusion
The analysis provides useful insights into retail sales performance, customer preferences, product categories, and purchasing behavior.
